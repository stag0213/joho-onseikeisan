# 音のデータ量計算マスター 〜高校情報Ⅰ対応〜

## 高校「情報Ⅰ」における「音のデジタル化（サンプリング周波数・量子化ビット数・チャンネル数）とデータ量の計算」を、インタラクティブに試しながら学べるWeb学習コンテンツです。

ブラウザ上で動作し、特別なサーバー構築やインストール作業なしでそのまま利用できます。

### 🌟 主な機能・特徴

*① 計算シミュレーター & 音質体験*

パラメータ（サンプリング周波数、量子化ビット数、チャンネル数、録音時間）をスライダーやボタンでリアルタイムに変更可能。

計算プロセス（bit → Byte → KB → MB → GB）を段階的に視覚化。

Web Audio API を活用し、パラメータを変更した際の「音質の劣化・ノイズ感・高音域の切れ」を実際に耳で試聴・体感できます。

*② 基礎解説と公式*

音のデジタル化の3ステップ（標本化／サンプリング・量子化・符号化）を分かりやすく解説。

計算の基本公式、単位変換のルール（8bit = 1Byteなど）、テストで注意すべき「ひっかけポイント」を網羅。

*③ 演習問題ドリル（自動生成）*

初級・中級・上級の3つの難易度別ランダム問題ドリル。

単位換算の基準（1 KB = 1000 Byte / 1 KB = 1024 Byte）の切り替えに対応。

回答後の自動採点および詳細な途中計算ステップの解説表示。

*④ 応用・逆算チャレンジ*

「CD-ROM (700MB) や SDカード (1GB) に最大何分間録音できるか？」など、記憶メディアの容量と音質設定から最大録音時間を求める実践的シミュレーション。

### 🚀 使い方・公開手順

ローカルで実行する場合

リポジトリをクローンまたは zip ダウンロードします。

index.html ファイルを任意のWebブラウザ（Chrome, Edge, Safari, Firefoxなど）でダブルクリックして開くだけで動作します。

GitHub Pages で公開する場合

本リポジトリを GitHub に push します。

リポジトリの Settings > Pages に移動します。

Source を Deploy from a branch に設定し、main (または master) ブランチの / (root) を選択して Save します。

発行された URL にアクセスすることで、生徒や学習者がブラウザから直接利用できるようになります。

### 🏫 教育現場での活用例

授業の導入・デモ: 教員がプロジェクターでシミュレーターを表示し、周波数やビット数を変えたときの音の違いを実演。

個人学習・個別最適な学び: 生徒各自がドリルを使って小テスト対策や計算演習を実施。

探究学習・発展: メディア容量と音質のバランス（圧縮効率やデータ量とクオリティのトレードオフ）に関する考察課題。
